¿Cómo funciona el consumo?

Resumen de los mecanismos utilizados en este portal.

1
Petición GET con fetch()

fetch(url) devuelve una Promesa que se resuelve con un objeto Response.

2
Validar el estado

Se revisa respuesta.ok; si el estado no es 2xx se lanza un Error controlado.

3
Convertir a JSON

await respuesta.json() transforma el cuerpo de la respuesta en objetos de JavaScript.

4
Renderizar en el DOM

Los datos se recorren con map(), filter() y sort() y se pintan como tarjetas de Bootstrap.

5
Encadenar servicios

Con el nombre de la capital se consulta Open-Meteo: primero el geocoding y luego el clima.

6
Manejo de errores

try / catch y .catch() muestran alertas amigables si falla la red o la API (por ejemplo, un 404).
